# つなげてポーカー（対戦パズル）

トランプ盤面で、**隣りどうし5枚をなぞってポーカーの役を作る**対戦パズル。CPUと同じ盤面で交互に役を作り、合計点を競う。

公開URL: https://takeshi-hariu.github.io/number-link-puzzle/

## モード（タイトルで選択）
- **ストーリー**：会話劇 → ポーカー対戦（vsキャラ）→ 会話劇、を5人ぶん。段位ごとに強い相手が登場（タロウ🌱→ハナ🎴→ジン⚡→カルメン🔥→ポーカー王👑）。勝てば次へ、負けたらリトライ。`CHARS`/`SCRIPT` を書き換えて差し替え可。
- **フリー対戦**：CPUと1試合。勝つと昇段（見習い→四段）していくランクラダー。
- **マジポカ**（旧マージ＆昇天）：一人用のステージパズル（**現在の本体＝`index.html`**）。5枚つないで役を作ると1枚に集約され、強い役ほど上のカードに育つ。各ステージの**天井＝目標カードを5枚つないで★**を出せばクリア。**補充は低い札のみ＝天井札は自分で作る**。**制限時間**あり。天井は St1=6 → … → 最終=A（激ムズ）。

## 遊び方

- 隣接する **5枚をなぞる** → ポーカーの役（**ワンペア以上**）が成立すると消えて得点
- **あなた → CPU 交互**、各 **6ラウンド**、合計点の高いほうが勝ち
- なぞる途中で役名がライブ表示（ワンペア→ツーペア→…と育つ）
- **役と得点**：ペア10／ツーペア20／スリーカード30／ストレート50／フラッシュ60／フルハウス80／フォーカード120／ストレートフラッシュ250／ロイヤル500
- **段位制**：見習い〜上位段で CPU の強さ・思考時間が変化。勝つと昇段演出。
- **斜めボーナス**：1ゲーム1回、斜め接続が使える（プレイヤー・CPU各1回）

技術：単一 `index.html`・Vanilla JS・依存ライブラリなし。
